# Ashby source notes

Documentation reviewed November 16, 2026. These describe available features, not the configuration of any particular employer. Verify current docs before making new product-specific claims.

- [Candidate Search](https://docs.ashbyhq.com/candidate-search): full-text search has word, phrase, case-sensitive phrase and variation modes, plus Boolean operators. The documentation does not prove how React versus React.js behaves in a specific configured search.
- [AI-Assisted Application Review](https://docs.ashbyhq.com/ai-assisted-application-review): employers enable AI review and set job-specific criteria. Evaluations can meet, not meet or be undecided. Reviewers can filter evaluations and sort by the proportion of criteria met. Our recommendations cannot reproduce hidden employer prompts.
- [Auto-Reject Applications](https://docs.ashbyhq.com/auto-reject-applications): employers can configure rejection conditions based on application answers. Wording changes in a CV do not resolve an eligibility condition.
- [Public Job Postings API](https://developers.ashbyhq.com/docs/public-job-posting-api): exposes posting descriptions and metadata. Its documented fields do not provide internal AI criteria or recruiter queries.

Report keyword and evidence coverage as the agent's own analysis, not an Ashby verdict. Confirming a vendor-specific matching hypothesis requires an authorized test workspace and controlled samples, not speculative claims based on a rejection email.
